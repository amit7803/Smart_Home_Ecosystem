# Smart Home Ecosystem

ESP32-based smart home hub with MQTT communication, automation, device management, and a local dashboard inspired by modern IoT ecosystems.

## Features

* Device Control (ON/OFF)
* MQTT Communication
* Automation Rules
* Local Dashboard
* Multi-device Support
* Sensor Monitoring
* Scheduling
* Expandable Architecture

## Hardware Used

* ESP32-CAM
* ESP8266 / ESP32 Clients
* Sensors
* Relays
* MicroSD Card

## Project Structure

```text
hub-firmware/
client-devices/
web-dashboard/
mobile-app/
images/
README.md
```

## How It Works

1. Hub manages connected devices
2. Devices send data using MQTT
3. Dashboard shows status
4. Automation runs based on rules
